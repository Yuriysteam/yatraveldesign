# Инструкция для Codex, получившего ZIP

Выполняй эту процедуру только после явной просьбы пользователя установить приложенный внутренний скилл.

1. Найди точный локальный путь ZIP и read-only проверь его список. Остановись при абсолютных путях, `..`, symlink entries или нескольких корневых папках.
2. Распакуй архив в новую временную папку. Не распаковывай поверх пользовательских файлов.
3. Убедись, что в единственной корневой папке есть `SKILL.md`, `codex-install.json`, `MANIFEST.sha256`, `doctor.sh` и `bootstrap.sh`.
4. Прочитай `codex-install.json` и выполни `bash doctor.sh --pack-only`.
5. Запусти `bash bootstrap.sh`. Запись в `CODEX_HOME` может потребовать системного разрешения; запроси его только для этого установщика.
6. Сообщи версию, постоянный путь и имя `$travel-product-context`. Попроси открыть новую задачу Codex.

Не перезаписывай существующую установку, managed copy или receipt. При конфликте путей, версии, manifest или checksum остановись. Не публикуй содержимое паспорта и не копируй его во внешние сервисы.
