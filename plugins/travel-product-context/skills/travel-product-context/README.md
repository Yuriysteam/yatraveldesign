# Travel Product Context

Приватный командный Codex-скилл с паспортом продукта Яндекс Путешествий. Внутри нет скиллов по спекам, Figma или дизайн-системе.

## Установка из общего Git-репозитория

1. Клонируйте приватный репозиторий.
2. В его корне запустите `bash install.sh`.
3. Откройте новую задачу Codex. Скилл доступен как `$travel-product-context` и может подключаться автоматически в релевантных продуктовых задачах.

Установка создаёт ссылку из `${CODEX_HOME:-~/.codex}/skills/travel-product-context` на клон. Поэтому после `git pull` база обновляется без повторной установки.

## Установка из ZIP без терминала

Передайте коллеге ZIP. Коллега прикладывает его к задаче Codex и пишет:

> Установи приложенный внутренний скилл Travel Product Context по инструкции CODEX_INSTALL.md. Не перезаписывай существующую установку.

Codex безопасно распакует архив, проверит состав и запустит `bootstrap.sh`. ZIP-версия сохраняется в постоянной versioned-папке внутри `CODEX_HOME`; временный файл не становится источником установленного скилла.

## Обновление общей базы

Для командной работы используйте Git: ветка → правка → `bash scripts/validate.sh` → pull/merge request → review. Подробности в `CONTRIBUTING.md`.

Паспорт начинается с [references/product-passport/README.md](references/product-passport/README.md). Репозиторий и ZIP содержат внутренние материалы и не должны публиковаться.
