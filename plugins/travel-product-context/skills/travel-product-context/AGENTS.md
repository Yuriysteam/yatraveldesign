# Travel product context

Этот приватный репозиторий содержит один Codex-скилл: `travel-product-context`. Он маршрутизирует запросы в паспорт продукта, лежащий в `references/product-passport/`.

- Для продуктовых, UX- и дизайн-задач следуй `SKILL.md`.
- Не загружай весь паспорт и большие JSON-каталоги без необходимости.
- Перед обновлением общей базы следуй `CONTRIBUTING.md`.
- После изменений запусти `bash scripts/validate.sh` и обнови версию, если меняется поставляемое содержимое.
- Репозиторий внутренний: не публикуй его и не копируй материалы во внешние сервисы без отдельного разрешения.
