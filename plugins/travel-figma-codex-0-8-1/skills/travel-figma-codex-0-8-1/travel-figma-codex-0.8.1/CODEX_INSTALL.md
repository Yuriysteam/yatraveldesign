# Инструкция для Codex, получившего ZIP

Выполнять только после явной просьбы пользователя установить приложенный внутренний Travel Figma Codex.

1. Найти точный путь ZIP и read-only проверить entries. Остановиться при абсолютных путях, `..`, symlink entries или нескольких корневых папках.
2. Распаковать архив в новую временную папку, не поверх пользовательских файлов.
3. Проверить наличие `codex-install.json`, `MANIFEST.sha256`, `doctor.sh` и `bootstrap.sh`.
4. Прочитать `codex-install.json`, выполнить `bash doctor.sh --pack-only`.
5. Запустить `bash bootstrap.sh`. Запись в `CODEX_HOME` может потребовать узкого системного approval.
6. Сообщить версию, постоянный путь и семь установленных skill names. Отдельно сообщить, найден ли опциональный BaseAI runtime; его отсутствие не отменяет установку пака. Попросить открыть новую задачу Codex.

Не перезаписывать существующие навыки, receipt или managed package. При checksum, manifest, path или ownership conflict остановиться. Пакет внутренний и не предназначен для внешней публикации.
