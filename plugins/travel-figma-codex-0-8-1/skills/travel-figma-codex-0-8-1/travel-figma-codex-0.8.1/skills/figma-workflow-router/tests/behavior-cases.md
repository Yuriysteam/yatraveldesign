# Проверка маршрутов

Исходные восемь маршрутов прошли независимый dry-run 2026-09-10. После замены редактора 2026-09-11 имена в каталоге ожидаемых маршрутов обновлены; отдельно повторно проверены три затронутых случая ниже. Реальных Figma-targets и записи не было. Это проверка решений агента по инструкциям, не гарантия автоматического выбора скилла или живой интеграции.

| Запрос | Проверенное ожидаемое решение |
|---|---|
| `$figma-spec-builder`: исправить только конец стрелки; экраны и тексты утверждены | Прямой сборщик, профиль стрелок и узкая проверка; без перепроектирования и редактора |
| «Figma Design Machine, перенеси принятый HTML, нужны только макеты» | Ведущий HTML-перенос; закончить после QA макетов; сохранить тексты |
| Спека из HTML, сохранение данных не согласовано | HTML-перенос → сборщик; приостановить только зависящее от неизвестного сохранения, продолжить подтверждённое |
| Новые макеты, подписи и затем спека | Сборщик координирует design-machine, DS и yandex-travel-ux-writing; QA новых макетов до возврата к сборке; без второго build |
| Проверить только компоненты и токены без изменений | Адресный read-only DS-аудит |
| Улучшить три кнопки без изменения Figma | yandex-travel-ux-writing; уточнить последствия действий, если без них текст не определён; Figma не нужен |
| Продолжить: HTML уже восстановлен в проверенные кадры, нужна только спека | Сборщик на готовых кадрах, повторного импорта нет |
| Спека из утверждённых макетов, yandex-travel-ux-writing отсутствует, тексты менять не надо | Сборщик; отсутствующий необязательный редактор не блокирует задачу |

После первого dry-run уточнены различие имени комплекта и явного профильного вызова, QA перед handoff и смена ведущего после завершённого этапа. Повторная проверка затронутых маршрутов не выявила новых блокеров.

## Проверка замены редактора — 2026-09-11

Независимый исполнитель прочитал новый редактор, все три обязательных reference и актуальный роутер 0.1.1. Дополнительные `ux-writing` и `store` не нужны. Проверены три случая:

| Запрос | Наблюдаемый результат dry-run |
|---|---|
| Ошибка поиска без известной причины и срока, нужен один текст | Только новый редактор; «Не удалось выполнить поиск». Без приветствия, вариантов, выдуманных причин, сроков и неподтверждённой кнопки повтора |
| Утверждённые тексты, только оформление спеки | Сборщик и нужные правила оболочки; редактор не подключается, тексты сохраняются |
| Новые подписи и спека по существующим макетам | Сборщик → редактор для новых строк → сборщик и QA затронутых экранов. Утверждённые строки сохраняются; design-machine не нужен без изменения самих макетов |

Для будущей ревизии дать независимому исполнителю сами запросы, текущий скилл и минимальные исходные данные; сравнивать выбранный маршрут, последствия для scope и критерии завершения. Не считать совпадение формулировок тестом поведения. Живую запись проверять отдельно на согласованном target.

## Смена артефакта и среды — 2026-10-01

| Запрос | Ожидаемое решение |
|---|---|
| Начали со спеки в Figma, затем пользователь просит локальный интерактивный HTML | Перестроить только оставшийся маршрут; Figma становится источником, подтверждённые сценарии и состояния переходят в HTML без повторного проектирования |
| «Не в Figma, а на локальном сервере» | Завершить Figma-маршрут; продолжить браузерную реализацию без требования подключить Figma, если повторное чтение источника не нужно |
| Серия мелких визуальных правок локального прототипа | На каждую правку — адресная проверка затронутого; полный QA не повторять до передачи или системного изменения |
| «Исправь исходник, архив не пересобирай» | Изменить только исходники; в финале явно указать, что архив оставлен без изменений |
| «Подготовь автономную сборку для внешнего сервера» | Проверить переносимость, относительные пути, локальные ресурсы и целевую среду; собрать самодостаточную папку, ZIP только если он отдельно запрошен |
| Комментарий-заглушка в исходном макете расходится с подтверждённой пользователем механикой | Применить подтверждённое решение пользователя; не трактовать заглушку как требование |
| Много однотипных карточек с новой интерактивной механикой | Сначала собрать и проверить несколько образцов и ключевое взаимодействие; масштабировать после подтверждения |

## Контроль живых изменений — 2026-10-05

| Запрос | Ожидаемое решение |
|---|---|
| «Исправь сначала один экран; остальные только после моего ОК» | Меняется только эталон. Подтверждение относится к показанной дельте; после изменения правила старое ОК не используется |
| «Это тестовые суммы, поменяй их в этих состояниях» | Правка классифицирована как демонстрационные данные и не объявляется глобальным продуктовым форматтером |
| «Исправь прототип, светлую и тёмную спеки и общий master» | Ведётся отдельная строка готовности для каждой цели; общий итог не объявляется, пока каждая строка не `done`, `blocked` или `cancelled by user` |
| «Во всех состояниях поменяй только значения ячеек» | До пакета зафиксированы allowlist текста целевых ячеек и защищённые geometry/linkage; изменение вне списка останавливает распространение |
| «Исправь этот экран; если причина в общем master — сначала предупреди» | Instance не даёт разрешения менять master; до отдельного согласия выполняются только аудит и безопасная настройка instance без detach |
| «Я не вижу добавленный блок» | Запись не повторяется автоматически: сначала стабильный read-back, проверка файла/страницы/узла и свежий screenshot |
