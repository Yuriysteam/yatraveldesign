# Changelog

## 0.4.1 — 2026-10-20

- Пояснения к макетам и спекам отделены от продуктовой микрокопии: их по умолчанию редактирует `figma-spec-builder` для аудитории handoff, без автоматического запуска UX-редактора.
- Добавлен регрессионный маршрут для переписывания документации без изменения утверждённых UI-текстов.
- Опциональные внешние модули указаны без локальных ссылок, чтобы основной командный ZIP оставался самодостаточным и продолжал устанавливать их отдельно.

## 0.4.0 — 2026-10-13

- Для Figma ↔ HTML добавлен обязательный readiness gate: snapshots, live Storybook/Figma libraries, component coverage и token coverage проверяются раздельно.
- Запрещён silent fallback на generic HTML и свободные Figma layers при неизвестном значимом компоненте.

## 0.3.0 — 2026-10-05

- Маршрут Figma → HTML теперь явно ведёт в `figma-to-baseai` с bundled BaseAI runtime и browser gate.
- Добавлен условный рубеж «эталон → явное подтверждение → распространение» с аннулированием подтверждения при изменении дельты или области.
- Контентные изменения разделены на продуктовые правила, редакционные правила и демонстрационные данные.
- Для нескольких артефактов/тем добавлена матрица готовности с отдельным статусом каждой цели.
- Пакетные записи получили mutation allowlist и protected invariants; изменение вне дельты останавливает распространение.
- Изменение общего master требует отдельного разрешения и проверки радиуса воздействия.
- Добавлен протокол расхождения read-back с отображением Figma без слепой повторной записи.

## 0.2.0 — 2026-10-01

- В маршрут добавлена среда запуска и явная смена целевого артефакта по последнему решению пользователя.
- Добавлены маршруты в локальный HTML-прототип и переносимую сборку; Figma может оставаться только источником.
- Зафиксированы реестр принятых решений, приоритет источников и защита от возврата исправленных ошибок.
- Разделены исходники и упаковка, добавлены пропорциональный QA, проверка механики на малом объёме и preflight переносимости.
- Добавлен reference `artifact-lifecycle.md` и новые поведенческие сценарии.

## 0.1.1 — 2026-09-11

- Редактор в маршрутах заменён с `sasha` на `yandex-travel-ux-writing` с включёнными ToV, редполитикой и методологией; отдельные `ux-writing` и `store` не являются зависимостями.
- Условия подключения редактора, сохранение утверждённых текстов и прямые вызовы профильных скиллов сохранены.

## 0.1.0 — 2026-09-10

- Добавлен единый вход комплекта: исходник и желаемый результат определяют ведущий скилл и необходимые этапы.
- Прямые вызовы сохранены; дизайн-система и редактор подключаются по условиям задачи.
- Зафиксирована передача контекста, продолжение завершённых этапов и защита от повторного импорта, дублирующей сборки и обратных вызовов роутера.
