# UX-редактор Путешествий

Один автономный скилл для дизайнеров Яндекс Путешествий: полный `ux-writing` 9.0.0, ToV, редполитика и командное правило диапазонов дат. Для передачи коллегам достаточно файла `yandex-travel-ux-writing.zip`.

## Как установить в Codex

1. Сохрани ZIP в папку, доступную Codex. Передай Codex путь к архиву и сообщение ниже.
2. Codex распакует скилл, проверит комплектность и напрямую откроет файл с приветствием. Если приложение запросит доступ к папке установки, разреши его.
3. Для следующего обращения начни новую задачу и вызови `$yandex-travel-ux-writing`. Если скилл не появился, перезапусти Codex.

Сообщение для установки — замени путь в квадратных скобках на путь к сохранённому файлу:

> Установи скилл из архива [путь к yandex-travel-ux-writing.zip] в мой пользовательский каталог скиллов Codex. Проверь содержимое архива, распакуй папку yandex-travel-ux-writing целиком, включая references, и проверь наличие SKILL.md. Если такая версия уже установлена, сохрани резервную копию вне каталога обнаружения скиллов перед заменой. После установки не завершай ответ сообщением о том, что скилл будет доступен позже: напрямую открой WELCOME.md из установленной папки и покажи его целиком. Для этого не нужно активировать новый скилл.

Установка вручную: распакуй папку `yandex-travel-ux-writing` из архива в `~/.agents/skills/`. Итоговый путь: `~/.agents/skills/yandex-travel-ux-writing/SKILL.md`. Это пользовательский путь в текущей [документации Codex](https://learn.chatgpt.com/docs/build-skills). Если твоя корпоративная сборка или SkillStore уже использует другой каталог, агент должен определить его по настройкам среды, а не создавать несколько копий.

Сам ZIP не запускает установку и приветствие автоматически. Внутри формата скилла нет команды, которая выполняется сразу после распаковки: приветствие в ответе установщика обеспечивает точный текст запроса выше. При короткой команде «установи скилл из архива» оно появится при первом вызове скилла следующим сообщением.

Для работы с текстами не нужны отдельные установки `ux-writing` и SkillStore, токены или доступ к внутреннему сайту. ToV и редполитика входят в пакет в текстовом виде. Подключение к Figma настраивается отдельно, если оно нужно.

## Как начать

Приветствие:

> $yandex-travel-ux-writing покажи инструкцию

Конкретная задача:

> $yandex-travel-ux-writing проверь текст ошибки по правилам Путешествий: …

Добавь контекст задачи и опиши, что нужно сделать с текстом. Можно попросить варианты, один итоговый текст, аудит всего экрана или черновое наполнение. Приветствие хранится в `WELCOME.md`: Codex показывает его в ответе на точный установочный запрос выше, а также при первом запуске скилла без конкретной задачи.

## Что внутри

- `SKILL.md` — правила работы и приоритет командной базы
- `references/ux-writing-v9.0.0.md` — полная неизменённая копия исходного скилла
- `references/voice-and-editorial.md` — правила Путешествий и дополнение про даты
- `references/examples-and-boundaries.md` — примеры и спорные места
- `references/sources/tov.txt` — полная текстовая копия ToV с маркерами страниц
- `references/sources/editorial.txt` — полная текстовая версия редполитики с дополнением о диапазонах дат
- `WELCOME.md` — приветствие для дизайнера
- `version.json`, `agents/openai.yaml`, `SOURCES.md` и `sources-manifest.json` — метаданные, происхождение и контрольные суммы источников

## Будущая загрузка в SkillStore

Пакет подготовлен локально и ещё не опубликован. Название для каталога: `yandex-travel-ux-writing`. Короткое и полное описания подготовлены в `version.json`; локальная версия сборки — 1.2.0, версию в каталоге назначит сервер.

Когда решишь публиковать, передай агенту со скиллом `store` распакованную папку и попроси загрузить её. Для нового скилла нужно выбрать существующую категорию из `store categories`. Категория намеренно не придумана заранее. Предпочитай загрузку распакованной папки: так CLI прочитает имя и описания из `version.json`; архив также поддерживается, но метаданные могут потребоваться явно.

Перед отправкой проверь итоговые имя и описания: по инструкции `store` описания задаются при создании карточки, а обновление версии их не меняет. После успешной загрузки SkillStore запускает проверку автоматически. До успешного ответа сервиса и его проверки нельзя утверждать, что скилл опубликован или доступен коллегам через каталог.

При обновлении базового `ux-writing` новая методология не подтянется автоматически. Замени включённую копию, сверь изменения с правилами команды, обнови сведения об источниках и пересобери архив.
