# Local Memory

Используй локальную память проекта для долговременного контекста между сессиями и агентами. Навык не привязан к конкретному человеку или компьютеру.

## Store

- По умолчанию: `.memory/` в корне текущего проекта.
- Скрипт: `.scripts/memory.mjs` в том же проекте.
- Для общей памяти команды задай абсолютный путь через `LOCAL_MEMORY_DIR`.

Не сохраняй новые записи в служебную память агента. Если там найден старый полезный контекст, перенеси только устойчивую часть в память проекта без дублей.

## Команды

Запускать из корня проекта:

```bash
npm run memory:add -- "Любит короткие ответы без вступлений" --category preference --tags style --source opencode
npm run memory:search -- "короткие ответы"
npm run memory:list -- --limit 20
npm run memory:context -- "дизайн процесс"
```

Для общей памяти команды или памяти другого проекта используй `LOCAL_MEMORY_DIR`:

```bash
LOCAL_MEMORY_DIR="/absolute/path/to/team-memory" npm run memory:list
```

## Что сохранять

- Предпочтения пользователя и стиль работы.
- Устойчивый проектный контекст.
- Принятые решения.
- Важные ссылки, владельцы, тикеты, повторяющиеся workflows.
- Исправления от пользователя о том, что было сделано неверно и как делать в следующий раз.

## Что не сохранять

- Секреты, токены, пароли и приватные credentials.
- Разовый вывод команд и временный debugging noise.
- Чувствительные персональные данные без явной просьбы запомнить.
- Догадки и непроверенные факты.

## Категории

- `preference` — личные предпочтения и стиль работы.
- `project` — устойчивый контекст проектов.
- `person` — информация о людях и командах.
- `process` — рабочие процессы и ритуалы.
- `decision` — принятые решения.
- `link` — важные ссылки.
- `note` — прочее.
