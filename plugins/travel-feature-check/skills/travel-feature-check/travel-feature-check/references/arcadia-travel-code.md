# Карта кода Travel в Arcadia

Карта задаёт стартовую границу поиска, а не доказывает полное владение каждым файлом. Пути подтверждены по индексу Arcadia и сервисным `a.yaml` 2026-09-08; перед выводом фиксируй фактическую ревизию текущего поиска, потому что структура может меняться.

## Подтверждённый зонтик

- `travel/**` — backend, Web, B2B, вертикали, общие API и библиотеки, аналитика и инфраструктура Travel; корневой `travel/a.yaml` объявляет сервис `travel`.
- `mobile/travel/**` — Android, iOS и общие мобильные модули Travel; корневые Android/iOS `a.yaml` объявляют сервис `travelapp`.

Полный индексный фильтр Travel:

```bash
ya tool cs 'ТЕРМ' -f '^(travel/|mobile/travel/)' -m50
```

Не используй один этот широкий фильтр для всей проверки. Сначала выбери профиль ниже; до полного зонтика расширяйся, если узкий проход не нашёл сущность или найденные связи выходят за профиль.

## Профили поиска

### Web-портал

```text
travel/frontend/portal/**
travel/frontend/ui-kit/**
travel/frontend/openapi*/**
```

### B2B Travel

```text
travel/frontend/portal/src/projects/b2b/**
travel/frontend/portal/server/**/b2b*
travel/frontend/portal/integration/**/b2b/**
travel/b2b/**
```

Для iOS и Android B2B не требуй наличия `b2b` в пути: ищи термины, модели и флаги задачи внутри всего корня выбранной мобильной платформы. B2B-логика может находиться в общих модулях приложения.

### Экстранет

```text
travel/frontend/extranet/**
travel/frontend/spec/hotels/extranet/**
travel/hotels/extranet/**
mobile/travel/android/apps/extranet/**
mobile/travel/android/feature/**/extranet/**
mobile/travel/ios/Extranet/**
mobile/travel/ios/Targets/Extranet/**
mobile/travel/ios/Targets/ProtoExtranet/**
mobile/travel/ios/Entitlements/Extranet/**
mobile/travel/ios/Tuist/ProjectDescriptionHelpers/Extranet/**
```

Web Экстранета использует контракт `travel/hotels/extranet/api/internal_api_gateway/openapi.yml`; проверяй его, когда поля, ошибки или ограничения API меняют видимое состояние.

### Мобильные приложения

```text
Android: mobile/travel/android/**
iOS:     mobile/travel/ios/**
Общее:   mobile/travel/shared/**
```

Экстранет — отдельное приложение на обеих платформах, а не только Web-раздел.

### Вертикали и общая логика

```text
Авиа:             travel/avia/**
Отели:            travel/hotels/**
Поезда:           travel/trains/**
Электрички:       travel/suburban/**
Автобусы:         travel/buses/**
Расписания:       travel/rasp/**
Заказы и оплата:  travel/orders/**
Общие контракты:  travel/api/**, travel/proto/**
Общие библиотеки: travel/library/**, travel/platform/**
```

`travel/analytics/**`, `travel/devops/**`, `travel/tools/**`, `travel/qa/**` и `travel/ai/**` принадлежат зонтику Travel, но не входят в проверку интерфейсной фичи по умолчанию. Подключай их только при найденной связи с видимым поведением.

## Порядок индексного поиска

1. Возьми тексты, сущности, действия, статусы и предполагаемые API-поля из тикета и Figma.
2. Первым запросом получи только пути, чтобы увидеть распределение совпадений:

```bash
ya tool cs 'ТЕРМ' -f '<профиль-путей>' -l -m500
```

3. Сузь поиск до найденных проектов и запроси контекст:

```bash
ya tool cs 'ТЕРМ|СУЩНОСТЬ|API_ПОЛЕ|ФЛАГ' -f '<найденные-пути>' -C2 -m50
```

4. Продолжай по импортам, маршрутам, моделям, действиям, ошибкам, OpenAPI-полям и экспериментальным флагам.
5. Если профиль ничего не нашёл, повтори поиск по `^(travel/|mobile/travel/)`. По всей Arcadia ищи только конкретный символ или зависимость, найденные в Travel-коде.

## Режим без checkout

`ya tool cs` ищет по индексу trunk и не требует mount. В этом режиме можно подтвердить существование файла, символа, строки и показанного индексом фрагмента, но нельзя утверждать поведение, для которого нужно прочитать окружающую реализацию или локальные изменения.

Если уже смонтированный безопасный checkout недоступен, не создавай новый. Отделяй подтверждённые совпадения от вывода и указывай в отчёте:

```text
Код проверен частично: доступен только индекс Arcadia; полное содержимое найденных файлов и локальные изменения не проверены.
```

## Проверка актуальности карты

Если поиск показывает, что код переехал, README ссылается на отсутствующий путь или сервисный `a.yaml` противоречит карте, доверяй текущему индексу и конкретным файлам. Укажи расхождение как ограничение; не достраивай новый путь по старой документации.
