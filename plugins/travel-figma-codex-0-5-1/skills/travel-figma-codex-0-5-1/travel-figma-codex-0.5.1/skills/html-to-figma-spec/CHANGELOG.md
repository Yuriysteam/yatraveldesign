# Changelog

## 0.1.1 — 2026-09-08

- Поддержаны переносимые source snapshots командной поставки: исходные пути, даты и hashes сохраняются, локальный `bundleSnapshot` используется как датированное evidence при отсутствии оригинального workspace.
- Уточнены границы snapshot-индексов: они не заменяют runtime прототипа, актуальную Figma-библиотеку или подключение плагина.

## 0.1.0 — 2026-09-08

- Создан вход HTML-прототип → компонентные экраны Figma → figma-spec-builder с сохранением подтверждённого решения.
- Добавлены статический инспектор HTML и общая карта соответствий с происхождением, типами ключей и отделением кандидатов от подтверждённых связей.
- Разделены декларации кода, наблюдаемое поведение, продуктовые требования и фактическая проверка в Figma.
