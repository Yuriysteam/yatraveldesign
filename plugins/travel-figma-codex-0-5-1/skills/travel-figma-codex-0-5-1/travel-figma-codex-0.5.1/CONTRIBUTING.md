# Обновление командного пака

Основная ветка приватного репозитория защищена. Изменения приходят через отдельную branch/PR.

1. Зафиксировать реальную обратную связь в `README.md` и `LEARNINGS.md`.
2. Сравнить предложения с актуальными версиями навыков и убрать уже покрытые пункты.
3. Изменить только затронутый skill и его поведенческие тесты.
4. Повысить версию изменённого навыка.
5. Повысить версию всего пака и обновить оба manifests и `CHANGELOG.md`.
6. Собрать новый release, запустить install/bootstrap smoke-tests и read-only forward-test.
7. Передать команде новый versioned ZIP; старый архив не перезаписывать.

В роутер не переносить конкретные размеры, тексты промо, частные анимации, продуктовые факты и реализацию HTML/CSS/JS. В пакет не добавлять паспорт продукта, секреты, доступы и персональные данные.
