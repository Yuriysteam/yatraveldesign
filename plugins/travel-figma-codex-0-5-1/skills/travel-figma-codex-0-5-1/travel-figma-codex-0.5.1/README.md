# Travel Figma Codex 0.5.1

Командный пакет для полного цикла работы с макетами и спеками:

- `figma-workflow-router` выбирает маршрут по исходнику, результату и среде запуска;
- `figma-design-machine` создаёт и исправляет продуктовые макеты;
- `figma-spec-builder` собирает сценарии, состояния, overlays, стрелки и handoff;
- `travel-figma-design-system` отвечает за компоненты, токены, иконки и provenance;
- `yandex-travel-ux-writing` пишет и проверяет интерфейсные тексты;
- `html-to-figma-spec` переносит согласованный HTML-прототип в Figma и спеку.

Паспорт продукта не включён. Если он нужен, установите отдельный внутренний пакет `travel-product-context`.

## Установка из Git

Клонируйте приватный репозиторий и запустите из его корня:

```sh
bash install.sh
```

Установка создаёт управляемые ссылки в `${CODEX_HOME:-~/.codex}/skills`. После `git pull` повторная установка не требуется.

## Установка из ZIP

Приложите ZIP к новой задаче Codex и напишите:

> Установи приложенный внутренний Travel Figma Codex по инструкции CODEX_INSTALL.md. Не перезаписывай существующие скиллы.

Codex проверит архив и запустит `bootstrap.sh`. После установки откройте новую задачу.

## Обновления

Правки возвращаются через branch/PR. После изменения любого навыка обновляется его версия, затем версия всего пака и `CHANGELOG.md`. Перед передачей обязательны `doctor`, smoke-tests и read-only поведенческая проверка из `SMOKE-TESTS.md`.
