# Проверка сборки

Дата: 19 октября 2026 года.

Проверена самостоятельная копия на отдельном локальном сервере, во вложенной папке. Сервер не предоставлял исходный проект и общую папку Base 2.0. Внешние запросы в функциональном прогоне были заблокированы.

| Проверка | Результат |
|---|---|
| Ресурсы HTML, CSS и SVG | Нет отсутствующих файлов и путей за пределы папки |
| Доступность файлов по HTTP | Все 98 файлов первоначальной сборки возвращают HTTP 200; этот отчёт добавлен после проверки |
| JavaScript | Оба файла проходят синтаксическую проверку; ошибок выполнения в прогоне нет |
| Шрифты | Все 14 локальных начертаний успешно загружены браузером |
| 13 сценариев × 2 темы | Пройдены 26 основных путей |
| Вложенные фильтры × 2 темы | Сортировка, пересадки, аэропорты, авиакомпании открываются и применяются |
| Загрузка | Обе строки шапки закрыты скелетонами перед результатом |
| Голосовые состояния | Проверены разрешение, отказ, повторный доступ, запись, обработка, ошибка и повтор |
| Ввод | Саджест заполняет поле; длинный текст прокручивается; при повторном открытии поле пустое |
| Ошибка запроса | Изменение открывает пустое поле; возврат работает |
| Изображения в браузере | Битых изображений нет |
| Прямое открытие index.html | Главная и текстовый сценарий до выдачи работают, ошибок и битых изображений нет |
| Внешние ресурсы интерфейса | Запросов к внешним хостам не обнаружено |
| Визуальная проверка | Главная в обеих темах, ввод и выдача проверены после завершения переходов |

Проверка выполнена в Chrome. Голосовые состояния проверены с искусственным аудиосигналом и отключённым сервисом распознавания: это проверяет интерфейс и предусмотренный демонстрационный результат, а не качество распознавания живой речи. Настоящий микрофон и SpeechRecognition зависят от разрешений, браузера и, при необходимости, его онлайн-сервиса.

Исходные файлы рабочего прототипа не изменены. В экспортированной копии изменены только пути к общим шрифтам и токенам; добавлены локальные зависимости и документация. Архив не создавался.
