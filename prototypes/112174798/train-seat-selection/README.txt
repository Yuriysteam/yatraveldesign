ЗАПУСК
Распакуйте весь архив в одну папку. Для локального просмотра нужен Python 3:
  python3 serve.py
После запуска откройте http://127.0.0.1:8780/
Список экранов: http://127.0.0.1:8780/screens.html
Другой порт: python3 serve.py 8781
Остановка сервера: Ctrl+C.

Можно разместить содержимое папки на любом статическом HTTP/HTTPS-сервере,
как в корне сайта, так и в подпапке. Главная index.html лежит в корне ZIP.
Открытие через file:// не поддерживается: оболочка работает с iframe,
а браузер ограничивает доступ между локальными файлами. Используйте сервер.

СОСТАВ
Desktop, Touch и App, обычный поезд и Сапсан; разное время прибытия;
двухэтажный поезд; вагоны без схем; туда-обратно и пересадка; загрузка,
ошибки загрузки и отсутствия мест, устаревшие результаты; каталог удобств.
Встроенная панель настроек переключает платформу, тему и состояния.
Все картинки, SVG, шрифты, CSS, JS и данные включены локально.
Установка npm-пакетов, доступ к Figma и интернет для просмотра не нужны.

ОГРАНИЧЕНИЯ ПРОТОТИПА
Данные демонстрационные. Это не сервис покупки билетов.
Выдача поездов и дальнейшее оформление представлены имеющимися заглушками.
Ссылка «Полные правила возврата» оставлена неподключённой, как в оригинале.
Архив содержит текущий основной прототип, без старых песочниц и резервных копий.

СБОРКА ДЛЯ ПУБЛИКАЦИИ
CSS-файлы размещены в корне. Пути к ресурсам в CSS не используют ../.
Пробелы в URL шрифтов закодированы для совместимости с проверкой загрузки ZIP.
