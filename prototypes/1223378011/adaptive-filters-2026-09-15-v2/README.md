# Адаптивные фильтры — прототип

Текущая интерактивная версия: фильтры, параметры поездки и экран объяснения рекомендаций. Данные и счётчики демонстрационные, не реальная выдача.

## Запуск

1. Распакуйте весь архив.
2. Убедитесь, что установлен Python 3.
3. На macOS откройте `Start.command`, на Windows — `Start.bat`.
4. Браузер откроется автоматически. Оставьте окно сервера открытым, пока смотрите прототип. Чтобы завершить работу, нажмите Ctrl+C в этом окне.

Если система не разрешает запуск файла, откройте терминал в распакованной папке и выполните `python3 start.py` (на Windows — `py -3 start.py`). Установка npm-зависимостей не нужна.

Не открывайте index.html двойным кликом: браузер блокирует загрузку модулей по file://. Для размещения на внутреннем статическом сервере скопируйте всю папку; точка входа — index.html.

## Содержимое

- Готовая страница и рабочие модули; правила баллов — в recommendation-engine.mjs.
- Собранная панель контекста и таблицы объяснений.
- Локальные шрифты, иконки и стили, уведомления о сторонних библиотеках.

Последние правила включают вечеринки для 5+ гостей, кроватку при наличии детей, усиление видов для двух взрослых без детей, квартиры от 14 ночей в городе и у моря, загородные дома у леса и гор. У леса и гор квартиры не рекомендуются. Учитываются выбранный тип жилья, наличие предложений и общий топ-5.

Это экспорт для внутренней демонстрации. Наличие фирменных шрифтов и ассетов в архиве не предоставляет дополнительных прав на их публичное распространение. Исследования, паспорт продукта, исходные выгрузки Figma, история задачи и node_modules не включены.
