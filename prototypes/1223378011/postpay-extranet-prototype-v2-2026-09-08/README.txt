Постпэй — прототип экстранета
Экспорт опубликованной версии от 8 сентября 2026 года.
Сайт: https://postpay-extranet-prototype-v2.surzhenkodmitry.chatgpt.site/

Точка входа: index.html в корне архива.
Для сервиса исследований или статического хостинга загрузите весь ZIP либо всё его содержимое, сохранив структуру папок.

Для просмотра на компьютере распакуйте архив и запустите локальный HTTP-сервер в этой папке. Например, при установленном Python:
python3 -m http.server 8000
Затем откройте http://localhost:8000/

Открытие index.html двойным кликом может блокироваться браузером: прототип использует JavaScript-модули, которым нужен HTTP-сервер.

Все изображения, иконки, стили и скрипты включены. Ресурсы из CSS встроены в стили для совместимости с импортом. Исходный сайт не изменён.
