# Еду по работе — статичный прототип

Вход: `index.html`. Мобильный и десктопный сценарии в одной сборке.
Для мобильного просмотра на компьютере: `mobile.html`.
Отдельный старт десктопа: `desktop-start.html`.

Для публикации загрузите содержимое этой папки на любой статичный хостинг.
Настройка перенаправлений и Python/Node-сервер не нужны.
Все ресурсы локальные; переходы используют hash-адреса `index.html#/...`.
Папку можно разместить на любом уровне сайта.

Сценарии:
- `index.html#/results` — обычная выдача;
- `index.html#/work/results` — включён рабочий режим;
- `index.html#/policy/results` — фильтр тревел-политики;
- `index.html#/policy/hotel/garden` — страница отеля.

Демонстрационные данные, без настоящей оплаты и бронирования.
Даты: 9–12 марта, Москва, один взрослый.
Дополнительные фильтры и счётчики частично демонстрационные.
После выбора номера — пустой белый экран с галочкой.
Ранее выявленные расхождения данных карточек и скидок в этой сборке сохранены.
Интеграция с Pathway не подключена.
