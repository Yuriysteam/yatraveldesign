# Метро в движении

Интерактивная схема с движущимися поездами и управлением скоростью.

## Открыть

В этой папке запустите локальный сервер:

```bash
python3 -m http.server 4179 --bind 127.0.0.1
```

Затем откройте `http://localhost:4179/`. Режим с круглыми точками включён по умолчанию.

## Состав папки

- `index.html` — карта и интерфейс;
- `app.js` — движение, остановки и скорость;
- `styles.css` — оформление;
- `river.svg` — исходный слой реки.

Река сейчас скрыта обратимым правилом `.river { display: none; }` в `styles.css`; сам файл сохранён.
