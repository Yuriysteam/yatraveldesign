Informer с кнопкой-иконкой ArrowRight
Informer с кнопкой-иконкой и многострочным текстом. Этот текст специально сделан длинным, чтобы продемонстрировать, как компонент ведет себя с ограничением по ширине в 500 пикселей. Дополнительный текст для увеличения длины: при использовании многострочного текста кнопка-иконка остается на своем месте, а текст корректно переносится на новые строки, сохраняя читаемость и визуальную структуру компонента.
