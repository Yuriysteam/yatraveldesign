# Библиотека иконок Travel

Локальный набор SVG для прототипов, импортированный из витрины `New icons`
в Travel.Styles.

- Исходный фрейм: [Travel.Styles · 9294:1052](https://www.figma.com/design/I8EBpOVkBHKTHVrDyWuaaIhI/Travel.Styles?node-id=9294-1052)
- Область импорта: только прямые компоненты, расположенные под заголовком
  `New icons`. Старые компоненты выше заголовка в библиотеку не попадают.
- Иконок в библиотеке: 856
- Нативные размеры: 12, 16, 20 и 24px
- Цветовая модель: монохромный `currentColor`

## Структура

- `index.json` — поисковый манифест с каноническим названием из Figma,
  размером, локальным путём, node ID и component key.
- `source-map.json` — данные об источнике и координаты, необходимые для
  повторной сборки библиотеки из полного SVG-экспорта Figma.
- `12/`, `16/`, `20/`, `24/` — SVG-файлы, сгруппированные по
  нативному размеру.
- `../_build/import-icons-from-figma-export.mjs` — повторяемый импортёр для
  нового полного SVG-экспорта того же фрейма Figma.

## Как использовать

1. Найди иконку в `index.json` по каноническому полю `name`, затем выбери
   точный нативный `size`, который требуется компоненту.
2. Используй путь из поля `path`. Не угадывай имя файла вручную.
3. Всегда задавай ширину и высоту явно. Не увеличивай глиф 16px до 24px, если
   существует нативная версия 24px.
4. Вставляй SVG инлайном, если он должен наследовать CSS-свойство `color`.
   SVG, подключённый через `<img>`, сохраняет внутренний цвет браузера по
   умолчанию и не наследует `color` родительского элемента.
5. Декоративные иконки должны быть скрыты от вспомогательных технологий.
   Значимое действие только с иконкой должно иметь доступное имя на
   родительском контроле.

Пример инлайн-подключения:

```html
<span class="action-icon" aria-hidden="true">
  <!-- содержимое BaseAI/icons/20/filter-new.svg -->
</span>
```

## Ограничения

- Используй глиф из встроенной библиотеки Travel, если задача явно не вводит
  новый утверждённый источник.
- Не перерисовывай, не растягивай и не поворачивай иконки. Не добавляй
  произвольные контейнеры, не меняй толщину штриха и не смешивай их с эмодзи
  или сторонним набором иконок.
- Сохраняй исходный viewBox, нативный размер и оптические поля.
- Не добавляй фиксированные цвета заливки в монохромные SVG — сохраняй
  `currentColor`.
