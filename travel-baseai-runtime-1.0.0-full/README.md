# Travel BaseAI Runtime 1.0.0-full

Отдельная внутренняя библиотека для генерации HTML-прототипов из Figma через `figma-to-baseai`.

Она содержит BaseAI-компоненты, сниппеты, токены, шрифты, иконки, иллюстрации и правила использования. Устанавливается один раз и не дублируется в каждом обновлении пака скиллов.

## Установка из ZIP

Приложите ZIP к новой задаче Codex и напишите:

> Установи приложенный внутренний BaseAI runtime по инструкции CODEX_INSTALL.md. Не перезаписывай существующие версии.

После установки `figma-to-baseai` найдёт библиотеку автоматически. Для работы с макетами и спеками без Figma → HTML этот архив не нужен.
